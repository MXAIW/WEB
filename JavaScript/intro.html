Интерпретируемый Интерпретатор - это программа, которая выполоняет другие программы

Переменные

переменную можно обьявить при помощи ключевого слова var, let либо же const.

var
Объявялет глобальную переменную, независимо от области видимости, в которой она объявлена;
let
Объявляет локальную переменную, такакя переменная существует только в той области видимости, в которой она объявляется;
const
Объявляет локальную константу;

Примечание: переменная неявна объявляется при использлованиию То есть если использовать необъявленную переменную, интрепетатор сам неявно её объявит

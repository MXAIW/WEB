Списки

Нумерованный список ― Order List

Создаётся дескриптором <ol>.

  1. Элемент 1;
  2. Элемент 2;
  3. Элемент 3;
  4. Элемент 4;
  5. Элемент 5;

Маркированный список ― Unordered List

Создаётся дескриптором <ul>.

  • Элемент 1;
  • Элемент 2;
  • Элемент 3;
  • Элемент 4;
  • Элемент 5;

Элементы списка ― ListItems

Как в нумерованном, так и в Маркированном списке элементы создаются дескриптором <li>.

Списки определений ― Definitions List

Создаётся дескриптором <dl>, что означает Description List.
Каждый элемент списка описыватеся двумя дескрипторами списка: <dt> — Desription Term и <dd> — Desription Details

Нумерованный список
Каждый элемент такого списка имеет точный порядковый номер;
Маркерованный список
Каждый элемент такого списка обозначен каким-то символом;
Список определения
Каждый элемент такого списка вводит понятия и даёт ему определения;

Вложенность

Списки можно вкладывать друг в друга как угодно, НО, вкладывать список непосредственно в другой список ЗАПРЕЩЕНО!!! Список можно вклдаывать только в элемент другого списка!!!
